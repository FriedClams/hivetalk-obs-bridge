# Security policy

This project is alpha software and has not received a formal security audit.

Please report a suspected vulnerability through GitHub's private vulnerability-reporting feature on the repository's **Security** tab. Do not open a public issue containing exploit details. If private reporting is unavailable, open a public issue asking the maintainer for a private contact method without including the vulnerability details.

The supported test version is the newest tagged GitHub Release. Review the release commit, automated test result, `package-lock.json`, and published SHA-256 hashes before running a downloaded artifact.
